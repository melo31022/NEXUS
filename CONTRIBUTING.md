# Contributing

Thanks for considering a contribution to NEXUS.

## Before opening a pull request

1. Explain the problem and the intended change.
2. Keep changes focused and avoid unrelated refactors.
3. Never include `.env`, API keys, logs, screenshots, or personal data.
4. Run the test suite: `python -m unittest discover -s tests -v`.
5. Update the README or changelog when behavior or commands change.

## Development setup

Use Python 3.11 or newer, create a virtual environment, and install `requirements.txt`.

## Pull requests

Include a concise summary, test results, affected Windows versions, and any limitations that still need manual verification. Do not claim Windows desktop behavior was tested unless it was tested on Windows.
